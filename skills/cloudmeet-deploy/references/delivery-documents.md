# 部署打包交付：资源、架构、功能与估价

## 1. 原表问题与输入

参考文件：`docs/视频会议系统部署配置及带宽需求汇总表.xlsx`（相对工作区根）。读取时只读；不存在时可依照此结构继续，不声称已读原文件。

已读原表含一张“部署配置及带宽”工作表，三列为人数、服务器配置需求、防火墙规则；覆盖1–50、51–100、201–300、301–500人，缺101–200。示例统一采用ARM64、openEuler、每节点8核32GiB/512GiB SSD，给出200Mbps至2Gbps带宽，统一列TCP 22/80/443/8888/8080和UDP 10000。

这些是历史规划，不是压测结果或任意实例默认值。人数未明确是总用户、峰值在线还是同时参会；服务器数量未说明角色、冗余与故障余量；带宽未分方向、分辨率和订阅路数；端口未注明来源、用途及是否公网。新文件须补足这些解释，而非只美化表格。

收集或记录为待确认：
- 版本、目标架构、OS、来源和部署范围；配置依据、采样/压测日期。
- 总注册人数、峰值同时参会人数、并行会议数、最大单会人数、每会人数分布。
- 视频分辨率/FPS、编解码、simulcast层、平均发送码率与订阅路数；音频、屏幕共享、TURN比例、录制需求。
- 外网/内网/跨地域、NAT/公网IP、上/下行或计费方向、带宽独享/共享、SLA及容量余量。
- 当前单机或多节点、JVB数量及分配、负载均衡能力、数据/会话共享、持久存储、备份、监控。
- 项目工作范围、角色费率、工作日小时数、币种税率、硬件采购或租赁、地域规格、报价有效期。

未知输入不填0冒充已确认；可先列显式假设和估算范围，等待确认。不为写文档连接服务器或启用新的收费资源。

## 2. 资源与端口工作簿

使用真正的xlsx生成库，例如已安装的openpyxl，缺依赖先报告并请求允许安装，或使用已可用的等效工具。不要改CSV扩展名。每表冻结标题、筛选、适当列宽、自动换行、标明单位；公式与输入区分色，未知值写“待确认”。

| 节点与服务 | 节点/区域/信任域、网关/Web/API/XMPP/Jicofo/JVB等角色、数量、每节点和合计资源、镜像架构、数据位置、备份/日志增长、容器限制、伸缩/故障边界；可选服务单列 |

单节点资源的合计不能重复把同机多个服务计成多台物理机。录制/转码资源单算；服务端运行资源与源码构建机资源分开。多台机器不自动形成HA；JVB失效通常不能保证正在进行的会话无损迁移。

### 带宽推导

使用场景输入而不是仅按人数查表。SFU简化规划：每会议N个发送端，平均每端入站码率b_send、每接收端订阅k路、每路平均b_recv，则桥入站约 `N × b_send`，出站约 `N × k × b_recv`；多会议分别计算再求和，并考虑音频、共享、协议开销、simulcast发送层、重传、冗余和容量余量。假设每人收所有人时k=N−1，但不能把该极端模型当所有会议默认。

分辨率不是固定码率保证，发送与接收码率不能不加解释设相同。TURN中继、P2P和录制独立标明路径及额外流量，避免重算；入口Web流量不代表媒体流量。月GB按实际平均Mbps×活跃秒数÷8÷1000计算，GiB则除1024³并正确转换字节；Mbps/Gbps、MB/GB和MiB/GiB不混用。结果是设计估算，须注明目标硬件/网络下压测后校准。

### 端口安全边界

- 从本次配置读取宿主映射与监听，逐条标明“实际/规划/条件示例”。不能把原表端口全部复制成公网0.0.0.0/0放行。
- HTTPS/WSS使用本次入口端口，不默认一定443；WebSocket/BOSH通常复用Web入口，不盲目增加公网端口。
- UDP媒体依据实际JVB映射/NAT公布地址配置。多个JVB需说明每台可达公网地址或唯一映射；普通HTTP负载均衡不能自动代理媒体UDP。
- SSH仅管理网段/堡垒机；80是否用于重定向或ACME验证依证书方案决定；8080、8888未证实用途前标待核对，不默认公网开放。
- XMPP、API内部端口、管理/健康指标接口、数据库默认仅内网/容器网；跨主机时只允许明确源地址。宿主映射和容器EXPOSE不是同一概念。
- TURN、VPN/FRP、录制等仅已确认启用时按实际配置补端口/中继范围及出站要求，不自行新增。说明DNS、NTP、镜像仓库、证书签发等条件性出站访问。
- 端口表与图中规则ID对应。文档建议不等于授权执行防火墙命令，不清空全局规则。

## 3. 架构图

`部署架构说明.md` 的标题下元信息行统一使用以下格式，不附加“草案”：

```text
版本 {本批次版本} · 服务器地址：{本批次完整origin} · 打包时间：{本批次打包日期YYYY-MM-DD}
```

例如：`版本 1.0.2 · 服务器地址：https://115.190.243.21 · 打包时间：2026-11-06`。示例值不是默认配置，实际值从本批次manifest读取；不要使用文档补写日期替代原打包日期。此页头格式优先于通用草案标注规则；去掉页头“草案”不代表已验收，正文继续如实保留配置依据、待确认项、规划边界及未验证说明。

交付可编辑Mermaid `.mmd`、中文架构说明 `.md`，优先用已有渲染器额外交付SVG/PNG并打开检查文字、箭头及排版；渲染工具不可用时说明仅交付源码、可视化未完成，不把源码称为图片。

依据已确认拓扑画现状图；建议扩容/高可用独立画规划图，用虚线/图例区分可选。至少表达：

1. 浏览器/Electron/Android、外网/互联网及DNS（适用时）、安全组/边界防火墙、入口公网地址/NAT。
2. 负载均衡有则画类型与职责（L4/L7、TLS透传/终止、WSS支持及会话约束）；没有则显式写“当前单入口，无独立LB”，不要为了图完整虚构组件。
3. 网关证书和信任根、公有CA或私有CA、证书覆盖名称/IP、续期；TLS终止后的内部HTTP或HTTPS真实标明。后端重加密要说明证书校验，不能把明文内网箭头写成SSL。
4. 业务Web/API与Jitsi信令路径、Prosody/Jicofo/JVB的控制关系、持久存储及管理区；逻辑服务与物理节点边界分开。
5. 媒体单独连到JVB（或已确认的P2P/TURN路径），标协议、端口、方向及NAT关系，避免画成所有媒体经HTTPS网关。

术语统一：HTTPS/WSS采用TLS（俗称SSL）；WebRTC媒体通常为DTLS-SRTP，与HTTPS链路分开。不能声称存在过时SSL协议或默认E2EE；经JVB的传输加密不代表服务端不可接触内容。端到端加密须有明确实现、客户端兼容和验证证据。证书用于信任和身份验证，不是另加的一层“SSL加密设备”。

单Web副本或SQLite等共享限制必须体现在LB/HA建议里：需要说明状态/房间/鉴权一致性、连接路由、共享数据、JVB发现与桥选择，不能仅“加LB加节点”就承诺横向扩展。未配置的SLA、故障切换、WAF、防DDoS不要写为既有能力。

## 4. 功能清单

输出xlsx（功能明细、范围与待验收）和便于审阅的Markdown；功能明细字段：

`ID / 模块 / 用户角色 / 功能 / 行为与限制 / Web覆盖 / Electron覆盖 / Android覆盖 / 实现状态 / 验证状态 / 版本与来源证据 / 验收标准 / 本次交付范围 / 可选依赖 / 备注`。

从本次源码/配置/测试或已确认发布说明提取。会议创建加入、身份角色、音视频、共享、成员管理、聊天、网络重连、安装升级、安全信任等是检查维度，不代表全部已实现。录制、E2EE、直播、容量HA、VPN等逐项证实，不把上游宣传页能力等同于本产品交付。

实现状态可为“已实现/部分实现/规划/不在范围/待确认”；验证状态独立为“通过/失败/未验证/不适用”，附证据和限制。例：MSI高版本升级有实现和策略测试，不等于实机升级已通过。历史版本测试不作为本批次直接证据。规划项不能混入基础报价或默认验收范围。

## 5. 硬件及软件报价估算

这是预算估算，不是正式供应商报价或合同承诺。Excel至少包含“估算参数、软件工时、硬件采购、云与持续费用、费用汇总、假设与排除”六张表，并附Markdown说明。输入单元格、公式单元格、单位及币种清晰区分，金额合理舍入但计算用原值。

### 软件工时（WBS）

逐项列 `工作包ID / 对应功能ID / 交付成果 / 角色 / 乐观-基准-悲观工时 / 费率(元/小时) / 小计 / 估算依据 / 验收项 / 是否包含`。

按范围分需求、设计、前后端、桌面/安卓、架构安全、部署集成、测试、文档培训、项目管理；没有的工作不要凑数。研发工作量、实际剩余工作与历史已投入工时分开；用户要全项目估价时不能只算本次修补工时，也不能把本次部署文档当全产品开发报价。依据可以是明确需求拆解、同类历史记录或专家假设，不能声称Git提交数等于真实工时。

公式：`软件人工=Σ(选用工时×对应角色小时费率)`。若按人天，注明每人天小时数，不能把元/人天当元/小时。给低/基准/高三档预算，或使用明确选择的PERT `(乐观+4×基准+悲观)/6`，说明方法。工时是投入量，不是自然日工期；周期还依赖人员并行度与依赖关系。

### 硬件与持续费用

- 采购硬件：型号/规格、数量、单价、合计、采购来源/日期/地域、保修、是否税运；网络设备、存储、备份等仅在范围内列入。硬件集成实施人工另归WBS，不用研发工时冒充机器售价。
- 云资源：实例、系统盘/数据盘、带宽包/公网流量、LB、存储、快照备份、监控、域名、证书及运维订阅；数量×周期×单价。云租赁和等效物理采购是替代方案，默认不要双算。
- 开源软件许可成本与适配集成人工分开。不要因组件开源就宣称全部软件免费/无合规义务；商用第三方许可、设备终端另列是否包含。
- 费率、硬件价格、税率或采购渠道未知时留“待确认/待询价”，可给标为示例的假设价格但不得混进“已确认金额”。需要当前市场价时经用户要求查询，附来源链接、规格和查询日期，不能编造供应商报价。

### 汇总与检查

一次性费用、按月费用、按年费用、选配费用分别汇总；按用户选择方案计算首年及三年TCO。明确运营月数、续费/折扣有效期、含税/未税口径。风险准备金=明确选定成本基数×风险比例；利润/管理费/税费分列，先说明计算基数和顺序，避免重复收费或重复加税。

缺价项目汇总显示“已知项小计（不完整）+待询价项数量”，不以SUM空单元格得出的0假装完整预算。所有工时和金额可追溯到输入及公式，人工复算至少一项和全部总计；需要Excel重新计算时设置重算标记，不能依赖未计算的公式缓存作为已验证数值。

## 6. 交付校验

- 批次目录 `delivery/` 保存四类资料以及 `交付文档清单.json`，含相对文件名、SHA256、版本、目标入口、架构、生成日期、现状/规划及未完成项。不得含秘密。
- 重新打开xlsx核对工作表/列、公式引用、实际写入的值与版本；检查不存在外部工作簿依赖和意外公式注入。来源文本写成文本，不执行内容。
- 图与端口表、节点资源、功能范围、报价数量一致；每类文档标草案/确认版及证据来源，不能用“已生成”暗示“已验收”。
- 只补资料不重新构建安装包，不改变版本计数；原文件及既有交付包不覆盖。缺输入可以交付带待确认项的草案，缺生成工具则报告对应项阻塞，禁止用Markdown文件冒充xlsx。
